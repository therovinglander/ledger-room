How it works
1
Skills compute. Deterministic Python (cash_kpis.py, accrual_kpis.py, anomaly_detection.py, reconciliation.py) reads raw CSVs and returns a KPI value plus the exact source row IDs it came from. No LLM ever touches a raw row.
2
Facts, not rows, go to the model. narrate.py enforces a contract in code: any fact with a value must carry a non-empty list of source IDs, or it's rejected before reaching the model.
3
Model narrates, code checks the narration. After the model writes the paragraph, validate_narrative() re-extracts every number and citation from the text and confirms it traces to an input fact. Anything unsupported is flagged, not hidden.
4
Verified across the whole portfolio. 25 synthetic businesses × both rooms (50 runs) produce zero uncited numbers and zero unresolved citations.
